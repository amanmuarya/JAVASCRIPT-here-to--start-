## arithmatic 

| Operator | Meaning             | Example             |
  --------   -------------------   ------------------- 
| `+`      | Addition            | `5 + 2 = 7`         |
| `-`      | Subtraction         | `5 - 2 = 3`         |
| `*`      | Multiplication      | `5 * 2 = 10`        |
| `/`      | Division            | `10 / 2 = 5`        |
 `%`       Modulus (Remainder)   `5 % 2 = 1`         
| `**`     | Exponent (Power)    | `2 ** 3 = 8`        |
| `++`     | Increment           | `x++` → `x = x + 1` |
| `--`     | Decrement           | `x--` → `x = x - 1` |

## comparison

Comparison Operators ka use do values ko compare karne ke liye hota hai.
Ye hamesha true ya false return karte hain

| Operator | Meaning                     | Example     | Output  |
 --------   ---------------------------    -----------   ------- 
| `==`     | Equal (value only)          | `5 == "5"`  | `true`  |
| `===`    | Strict Equal (value + type) | `5 === "5"` | `false` |
| `!=`     | Not Equal                   | `5 != 3`    | `true`  |
| `!==`    | Strict Not Equal            | `5 !== "5"` | `true`  |
| `>`      | Greater Than                | `10 > 5`    | `true`  |
| `<`      | Less Than                   | `5 < 10`    | `true`  |
| `>=`     | Greater Than or Equal       | `5 >= 5`    | `true`  |
| `<=`     | Less Than or Equal          | `5 <= 3`    | `false` |

## ornary 

Unary Operator wo operator hota hai jo sirf ek operand (ek value/variable)
 par kaam karta hai.

 | Operator | Meaning           | Example         |
| -------- | ----------------- | --------------- |
| `+`      | Convert to Number | `+"10"`         |
| `-`      | Negate Number     | `-5`            |
| `++`     | Increment         | `a++`           |
| `--`     | Decrement         | `a--`           |
| `!`      | Logical NOT       | `!true`         |
| `typeof` | Check Data Type   | `typeof "Aman"` |

## Ternary Operator ** ek short form of if...else hai.
Isme 3 operands hote hain, isliye ise Ternary Operator kehte hain.
