Welcome to my JavaScript learning repository! 🚀

My goal is to build strong JavaScript fundamentals and prepare for modern web development using React and other technologies.

## 📚 Topics Covered

The following topics are organized according to my learning folder structure.

| No. | Folder Name | Topics Covered |
|---|---|---|
| 01 | `1-script` | Introduction to JavaScript, script tags, and connecting JavaScript with HTML |
| 02 | `2-dataType` | Variables, primitive and non-primitive data types, type conversion |
| 03 | `3-Operators` | Arithmetic, assignment, comparison, logical, and other operators |
| 04 | `4-controlFlow` | Conditional statements, `if-else`, `switch`, and decision-making |
| 05 | `5-loop` | `for`, `while`, `do-while`, `for...of`, and `for...in` loops |
| 06 | `6-function` | Function declarations, expressions, arrow functions, parameters, and return values |
| 07 | `7-Arrays` | Array creation, array methods, iteration, and array manipulation |
| 08 | `8-object` | Objects, properties, methods, and object manipulation |
| 09 | `9-DOM` | DOM selection, element manipulation, and dynamic HTML updates |
| 10 | `10-Event handling` | Event listeners, mouse events, keyboard events, and form events |
| 11 | `11-FromsAndValidation` | HTML forms, input handling, and form validation |
| 12 | `12-localStorage, session` | Local storage, session storage, and browser-side data storage |
| 13 | `13-srope` | Global scope, function scope, block scope, and lexical scope |
| 14 | `14-this-keyword` | The `this` keyword and its behavior in different contexts |
| 15 | `15-Object-Oriented-js` | Objects, constructors, prototypes, classes, inheritance, and OOP concepts |
| 16 | `16-Callback` | Callback functions and asynchronous programming fundamentals |
| 17 | `17-all type.js` | Additional JavaScript examples and practice programs |

*Note: The descriptions above are based on the folder names. The exact topics may vary depending on the code inside each folder.*
