## Data type -- defines the type of value that a variable can store in JavaScript.

✅ Primitive: String, Number, Boolean, Undefined, Null, BigInt, Symbol
✅ Non-Primitive: Object (Array aur Function bhi object category me aate hain) ,, jisme bracket ata hai vo rafrence hota hia aur use copy nhi kar skte hai 

object = { }
function = ( )
array  = [ ]
me creat hota hai 

##  dynamically

JavaScript is a dynamically typed language because the data type of a variable is determined automatically at runtime and can change when a new value is assigned.

🎯 Yaad Rakho
✅ Type manually declare nahi karna padta.
✅ Variable ka type runtime par change ho sakta hai.
✅ Isliye JavaScript ko Dynamically Typed Language kehte hain.

## Type Coercion in JavaScript

Type Coercion = Jab JavaScript automatically ek data type ko dusre data type me convert kar deta hai operation perform karne ke liye.

✅ + → Agar String ho, to String conversion karta hai.
✅ -, *, / → Mostly Number conversion karte hain.
✅ JavaScript ye conversion automatically karta hai.
